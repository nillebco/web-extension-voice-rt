# Changelog

## 0.3.0

- Building the extension for Safari (MacOS and iOS)
- Function calling is now supported.
  - Added a function to stop the voice session. Say goodbye and the session will be closed.
  - Added a function to change the background color of the page.
  - Added a function to get the current page URL.
  - Added a function to get the HTML of the current page.
  - Added a function to copy text to the clipboard. Works only if the window is focused.
- Stop the voice session from the page itself
- On mobile, display a larger "Voice Session Ready" window.

## 0.2.1

The first working version.
Available for Chrome. Speak with a web page. Packaged with vite.
Lets you specify an API key or a Key Exchange server (who will be supplying a key - a temporary one).
